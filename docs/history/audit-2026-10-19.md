# The audit of 2026-10-19

Erik asked whether everything added so far is necessary, whether the patches carry redundant code, and whether the
planning/worker split is efficient. Four read-only agents audited the patches, src/ and config/, tools/ and docs/,
and the orchestration's cost from the session transcripts and git. This file keeps their findings and Erik's calls,
and maps each finding to the task that handles it. The working rules that came out of it are in docs/approach.md.

## Findings and where they go

### Defects (task 093 unless noted)
1. `tools/stutter_check.sh` times a window run but has no check that the window is on screen; a covered window runs
   without vsync (task 091-display-rate-margin), so its PASS can measure nothing.
2. hud_check.sh:69, flash_check.sh:152, framerate_check.sh:214, billboard_check.sh:75, sas_reverb_check.sh:62 and
   display_rate_check.sh:536 build their memory stick with `ln -s`; under Git Bash that copies the 253 MB disc.iso.
   `port.fresh_stick` and frame_regress.sh:176 use hard links on Windows.
3. out/gerec/*.gerec date from Oct 6, before texture mapping, mips, the colour test, dither and CLIPENABLE entered the
   format; replay_check.sh:45 and gerec/metal_check.sh:76 reuse existing recordings, so the Metal-against-Vulkan
   replays never exercise those.
4. The record backend does not forward patch 0017-internal-scale-by-backend's `supports_internal_scale`, `set_internal_scale` and `target_size`
   (the Resolution row disappears under it). Task 095.
5. The scorecard has not run since Oct 8, across 21 patches. Task 096.
